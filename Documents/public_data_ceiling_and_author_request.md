# Public-Data Ceiling and Author Metadata Request

## Purpose

This document defines the current evidence ceiling for this repository. The
goal is to keep future work focused on new, defensible insight about the
therapeutic promise and limits of SRSC-exosome and FOXO3A-enrichment strategies
without presenting unsupported causal claims.

The repository can still produce useful analyses from public data. It should
also make clear when stronger conclusions require missing author-side metadata.

## Current Defensible Outputs

With the public files currently available in this repository, the following
outputs are defensible when generated by the guarded pipeline:

- Reproduced macaque transcriptomic aging-clock behavior and tissue-level
  rejuvenation summaries.
- Covariate-aware tissue expression effects, subject to the quality of released metadata and the available covariates.
- Conservative plasma biomarker ranking and plasma-to-animal mapping audits.
- Explicit estimability gates for mediation and causal decomposition.
- Mouse exosome mechanism-support summaries from `OMIX009283`, interpreted as
  cross-species exosome-alignment support rather than direct primate causal
  evidence.
- `OMIX007582` technical-ID methylation audits and bounded Mammal40 rebuild
  smoke tests.
- `OMIX009284` read-only structural audit showing PBMC single-cell RNA data with
  recoverable suffix-to-sample mapping.

## Current Non-Defensible Claims

The public data do not currently support the following claims as reliable
scientific conclusions:

- A numeric causal partition of macaque rejuvenation into exosome-derived and
  purely cellular components.
- Direct evidence that exosomes are the main cause of the observed primate
  rejuvenation effect.
- Direct mediation from plasma or exosome cargo to tissue rejuvenation unless
  linked animal-level assumptions are met.
- A biological methylation validation result from `OMIX007582` beta-matrix
  columns, because the technical-to-biological sample key is missing.
- A cross-tissue mechanism conclusion from `OMIX009284`, because the audited
  release is PBMC-only single-cell RNA data.
- A causal claim that FOXO3A enrichment is necessary or sufficient for the
  observed therapeutic effect without direct intervention-linked cargo,
  recipient, and outcome mapping.

These points can be discussed as hypotheses or motivation, but not as
interpretation-facing results.

## Hard Public-Data Limits

The current public-data ceiling is driven by four missing linkage layers:

1. Plasma-to-bulk animal linkage is incomplete.
2. Direct exosome cargo-to-recipient animal linkage is not available.
3. `OMIX007582` Mammal40 beta columns use technical Sentrix IDs that cannot be joined to released biological metadata from public files alone.
4. Treatment-era controls, stage controls, and reduced public subset files
   require careful separation; collapsing them would inflate interpretability.

If these limits remain unresolved after all reproducible public-data audits are complete, additional mechanistic claims should be treated as speculative.

## Metadata That Would Increase Evidence Strength

Requesting the following files or tables from the authors would materially
improve scientific validity:

- A plasma proteomics `sample_id -> animal_id -> group -> sex -> age` key for
  all `OMIX007581` columns.
- A bulk RNA-seq `sample_id -> animal_id -> tissue -> group -> sex -> age` key
  confirming the current metadata harmonization.
- An exosome cargo sample map linking exosome preparation, donor animal, cargo
  measurement, treatment arm, and recipient outcome where applicable.
- The `OMIX007582` Mammal40 sample sheet linking Sentrix barcode/position IDs
  such as `207925070004_R01C01` to biological sample, tissue, group, sex, and
  age.
- Any QC/exclusion table used by the authors for RNA-seq, plasma proteomics,
  methylation arrays, and single-cell PBMC data.
- The exact SRSC/exosome preparation metadata, including source cells, FOXO3A
  manipulation or enrichment validation, dose, injection schedule, batch, and
  recipient mapping.
- Any direct exosome uptake, biodistribution, or cargo-transfer measurement
  linked to recipient animals and tissues.

## Evidence Upgrade Rules

The repository should use these upgrade rules before strengthening claims:

- Level 1: macaque rejuvenation is reproduced from public data.
- Level 2: Level 1 plus reliable plasma-to-animal linkage supports plasma
  association.
- Level 3: Level 1 plus orthogonal exosome-alignment or validation support.
- Level 4: linked mediation estimable under stated animal-level assumptions.

Without the missing author-side keys above, the repo can usually support Level
1 to Level 3 evidence, but not Level 4 causal decomposition.

## Author Request Draft

Suggested request:

```text
Dear [Author Name],

I am building a reproducible reanalysis of the public SRSC multi-omics data to
understand which rejuvenation signals are tissue-intrinsic and which are more
consistent with plasma/exosome-associated mechanisms. The current public files
support guarded reproduction and alignment analyses, but several sample-linkage
tables appear necessary for scientifically valid causal interpretation.

Would you be willing to share, or clarify the availability of, the following
metadata tables?

1. Plasma proteomics sample-to-animal mapping for OMIX007581.
2. Bulk RNA-seq sample-to-animal/tissue/group mapping used in the study.
3. Mammal40 Sentrix barcode/position to biological sample mapping for
   OMIX007582.
4. Exosome preparation/cargo/donor/recipient linkage metadata, if available.
5. QC/exclusion tables used before the published analyses.

The goal is not to overstate the public data, but to determine which mechanistic
claims can be supported reproducibly and which should remain hypotheses.

Best regards,
[Name]
```

## Operational Rule

When future analysis reaches a result that depends on one of the missing keys in
this document, the pipeline should either:

- emit a structured non-estimable output with the missing key named explicitly
  in `missing_author_key` and a stable `reason_code`,
  or
- downgrade the result to hypothesis-generating language.

Do not fill these gaps with positional joins, order-based mappings, or
cross-species substitution unless the output is clearly labeled exploratory.
